## ⚡ Core Value Propositions

- **1:1 Pixel-Perfect Figma Translation:** Full variable and token fidelity, responsive auto-layout preservation, and fluid typography curves.
- **Sub-Second Speed Engineering:** Sub-800ms Largest Contentful Paint (LCP), 0.000 Cumulative Layout Shift (CLS), and 99+ mobile Lighthouse scores.
- **Micro-Interaction Polish:** 60fps GPU-accelerated transforms, accessible state transitions, and sub-50ms Interaction to Next Paint (INP).

---

## 🛠️ Architecture & Tech Stack

- **Framework:** React 19 + TypeScript (Strict)
- **Bundler:** Vite 8 (Sub-350ms production builds)
- **Styling:** Tailwind CSS v4 + Custom Hairline Design Tokens
- **Icons:** Lucide Icons (Zero runtime external asset dependencies)
- **Deployment:** Vercel Edge Network / Static Export

## 📦 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node v25)
- npm, pnpm, or bun

### Local Installation

```bash
# Clone the repository
git clone https://github.com/Nkagyeman/vanguard-studio-showcase.git
cd vanguard-studio-showcase

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
